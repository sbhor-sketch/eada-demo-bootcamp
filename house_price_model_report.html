How to read the KPIs

  • MAE: average absolute dollar error; easy to interpret.
  • RMSE: penalizes large misses more heavily; used to rank the models above.
  • R²: fraction of price variation explained (closer to 1 is better).
  • RMSLE: error on log prices; useful when relative price errors matter.

Data and evaluation

  • 1,460 labeled homes, 79 input columns, target: SalePrice.
  • Random 80/20 train/validation split; random seed 42. Validation rows were not used to fit models.
  • Missing values are imputed; categorical features are one-hot encoded. Input ID is excluded.
  • Neural network is a small 64→32 MLP with early stopping. Tree ensembles use limited depth/estimators for fast training.
  • Not run: XGBoost could not load its native runtime (XGBoostError). Hist Gradient Boosting is included as a fast boosting alternative.
